2.0 부터 연결 코드는 없습니다. 인자가 붙어 있어도 **무시하고 인자 없이** 아래를 실행하세요. 이 명령은 **기다리지 않고 바로 끝납니다**(리스너 기동 + 브라우저 열기 + 주소·확인값 출력):

```bash
node "${CLAUDE_PLUGIN_ROOT}/bin/vibeagent-connect.mjs"
```

**1단계 — 출력을 사용자에게 바로 전달하세요(기다리기 전에).**
- 출력이 **`브라우저에서 연결을 진행하세요: <주소>`** 로 시작하면 "브라우저에서 프로젝트를 고르고 [연결]을 눌러 주세요(브라우저가 안 열렸으면 주소를 `#` 뒤까지 복사해 이 PC 의 브라우저에서 여세요)" 라고 한 줄 알리세요. 주소를 대신 열거나 요약하지 마세요. 출력의 **`확인값 …`** 줄은 그대로 함께 전달하세요 — 브라우저 화면에 같은 값이 보여야 이 PC 의 연결입니다(다르면 그 탭을 닫고 다시 실행).
- 출력 첫 줄이 **`이전 연결 시도가 실패했어요(…)`** 이면 그 문장을 사용자에게 전달하고 계속 진행하세요(새 대기는 이미 시작됐습니다).
- 출력이 **`진행 중인 연결 대기에 이어 붙었어요`** 로 시작하면 이전에 띄운 대기가 아직 살아 있는 것입니다. 인자 없는 실행이면 스크립트가 **같은 연결 주소를 브라우저에 다시 엽니다**(`--wait` 폴링은 열지 않음). 그 문장과 주소·확인값을 사용자에게 그대로 전달하세요. 사용자가 새로 시작하길 원하면 `--restart` 를 붙여 실행하세요.
- **`PAX 연결 완료:`** 가 이미 나왔다면(이전 대기가 그 사이 끝난 경우) 3단계로 바로 가세요.

**2단계 — 30초씩 기다리며 확인하세요.** 사용자에게 안내한 뒤 아래를 실행하고, 마지막 줄이 **`waiting:`** 이면 같은 명령을 다시 실행하세요(**최대 20회** ≈ 대기 수명 10분). 재실행은 진행 중인 대기에 **이어 붙을 뿐** 새 탭을 열지 않습니다. 20회 뒤에도 `waiting` 이면 "브라우저에서 [연결]을 누른 뒤 `/pax-preview:connect` 를 다시 실행해 주세요" 라고 안내하고 멈추세요.
  ```bash
  node "${CLAUDE_PLUGIN_ROOT}/bin/vibeagent-connect.mjs" --wait 30
  ```
**3단계 — 결과 처리.**
- **종료 코드 4**(`listener_failed`): 출력의 로그 경로를 사용자에게 알리고, 샌드박스 제한이 의심되면 "터미널에서 직접 실행" 을 안내하세요.
- **`연결 실패 —`** 로 끝나면 그 문장을 사용자에게 그대로 전달하세요. 코드는 1회용이라 `/pax-preview:connect` 재실행이 유일한 재시도입니다.
- **`PAX 연결 완료: <저장소>`** 가 나오면 사용자에게 다시 묻지 말고 곧바로 이어서 진행하세요. "연결됐어요. 이어서 이 프로젝트의 로컬 개발 환경을 준비할게요." 한 줄 뒤 **`pax-local-setup` 스킬**을 따라 clone → 환경변수 → 개발 서버 실행까지 자동 수행하세요. 그 저장소 주소를 기억해 두고, 스킬 1단계에서 `get_project_manifest` 의 `repoUrl` 과 **반드시 대조**하세요(다르면 멈추고 사용자에게 알림 — 다른 세션의 연결이 섞인 것). 출력에 **`folder_mismatch: repo=<주소> suggest="<경로>"`** 줄이 있으면(지금 폴더 ≠ 고른 프로젝트) 이 폴더에서는 **아무것도 진행하지 마세요**(도구도 이 폴더에선 그 프로젝트를 쓰지 않습니다). 대신 사용자에게 한 번만 물으세요: "지금 폴더는 P1 이에요. 방금 고른 P2 를 `<경로>` 에 내려받아 준비할까요?" — **예**면 `git clone <주소> "<경로>"`(경로는 따옴표째 — 공백 대비; 사용자 본인 GitHub 인증; `exists=1` 이면 clone 생략) → `node "${CLAUDE_PLUGIN_ROOT}/bin/vibeagent-sync-skills.mjs" --project-dir "<경로>"` → "`<경로>` 를 열고 새 대화에서 '이 프로젝트를 로컬에서 개발할 수 있게 준비해줘' 라고 하세요(환경변수·개발 서버는 그 대화에서 이어져요)" 로 마무리. **아니오**면 "P2 는 P2 폴더에서, 이 폴더의 P1 은 `/pax-preview:connect` 로 다시 연결" 만 안내하고 멈추세요.
