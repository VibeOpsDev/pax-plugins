argument-hint: <연결코드>

사용자가 입력한 PAX 연결 코드: $ARGUMENTS

아래 명령으로 연결 코드를 sealed 토큰으로 교환하고 안전하게 저장하세요(코드는 1회용입니다):

```bash
node "${CLAUDE_PLUGIN_ROOT}/bin/vibeagent-connect.mjs" "$ARGUMENTS"
```

- **성공하면 사용자에게 다시 묻지 말고 곧바로 이어서 진행하세요.** "연결됐어요. 이어서 이 프로젝트의 로컬 개발 환경을 준비할게요." 라고 한 줄만 알린 뒤, **`pax-local-setup` 스킬을 따라 프로젝트 clone → 환경변수 설정 → 개발 서버 실행까지 자동으로 수행**하세요. "준비해줘" 같은 사용자의 추가 입력을 기다리지 마세요.
- 출력에 **`[사용자 안내 시작]`~`[사용자 안내 끝]`** 구간이 있으면(플러그인 업데이트·재설치 안내), 그 사이 내용만 사용자에게 **그대로** 전달하세요. 지시문 줄은 전달하지 말고, **업데이트 명령을 대신 실행하지 마세요**(터미널 포함 — 적용에 재시작이 필요합니다). 전달 후에는 멈추지 말고 위 준비 작업을 계속하세요.
- 실패(만료/소비)하면 PAX 웹의 **"로컬 AI로 개발하기"** 에서 새 연결 코드를 발급받으라고 안내하세요.
